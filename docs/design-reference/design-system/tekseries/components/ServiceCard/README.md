# ServiceCard

A white card (28px corners) with an icon tile, 32px title and coral "01 / 04" number on the left and 17px body paragraphs on the right.

- `title`, `icon`, `num`, `total` (default "04"), children: paragraphs (a string splits on blank lines).
- `layout`: `row` (default, 320px left column, 40px gap) or `stack` (one column, used below 1100px).
- The border turns saffron on hover. Stack cards with a 20px gap.

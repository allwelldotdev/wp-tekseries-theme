# CtaCard

A 32px-cornered card that carries an eyebrow, a 28px statement and an optional button.

- `tone`: `saffron` (default; ink text, dark button) or `plum` (white statement, mist body, saffron eyebrow, accent button).
- `eyebrow`, `title`, `actionLabel`, `href`; children go under the statement (the Mission card's paragraphs, 18px / 1.65).

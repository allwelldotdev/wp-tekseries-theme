# NavLink

Header navigation pill: 16px semibold plum text, 8/14px padding, lilac fill on hover or when `active`.

- Set `href`; `active` marks the current page (`aria-current="page"`).
- Row gap 4px on a white header with a 1px line-coloured bottom border. Below 1100px the row collapses to a 44px menu button.

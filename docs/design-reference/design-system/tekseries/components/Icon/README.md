# Icon

A Material Symbols Rounded glyph (weight 400, outline) chosen by its ligature `name`.

- Names in use: `hub`, `lightbulb`, `settings_suggest` (pillars), `co_present`, `potted_plant`, `emoji_events`, `work` (services), `menu`, `close` (mobile nav). Any name from Google's Material Symbols set works.
- `size` in px (default 24). It takes the text colour unless you pass `color`.
- Decorative by default; pass `aria-label` when the icon carries meaning alone.

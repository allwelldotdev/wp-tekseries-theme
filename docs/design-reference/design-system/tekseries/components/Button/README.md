# Button

Pill-shaped link button in bold Onest; every action on the TekSeries site uses it.

- `variant`: `primary` (plum, turns saffron on hover), `soft` (lilac, header "Job Series"), `dark` (ink, inside saffron cards), `accent` (saffron, on plum; turns white), `outline` (white 70% border, on plum only).
- `size`: `lg` 14/26px padding, 17px (hero, stat bar; default) · `md` 12/22px, 16px (cards) · `sm` 10/18px, 16px (header).
- Renders an `<a>`: pass `href`. Optional `icon` takes a Material Symbols name.
- Pair at most two buttons: one filled, one soft or outline. Text on saffron is always ink.

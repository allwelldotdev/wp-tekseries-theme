Block theme for tekseries.com.

== Description ==

TekSeries is the block theme for tekseries.com, the site of TekSeries, a non-profit that equips graduates with practical AI skills. It carries events, news, a photo and video gallery and the Job Series job board. Editors change every page, the header, the footer and the colours in the Site Editor without code. Pair it with the TekSeries Blocks plugin.
